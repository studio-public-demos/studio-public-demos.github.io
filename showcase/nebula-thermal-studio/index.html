01 / The actual engineering challenge

Will the enclosure manage the heat generated inside it?

For a combiner box, fuse-link resistance, copper branch wiring, output conductor sizing, disconnect contacts, monitoring electronics, solar exposure and thermal behavior all matter. Simply knowing a switch is rated 400 A does not verify its installed enclosure's temperature rise.

Published product

Specific electrical topology

Trinity Touch's 16-input / 1-output reference provides rated voltage, channel measurement capability and switch rating. The published exterior measures 1210 × 748 × 250 mm including mounting clamps.

Third-party fuse evidence

Loss is current dependent

ETI publishes 1.3 W at 14 A and 3.2 W at 20 A for a 20 A, 1000 V gPV fuse. We interpolate only between those documented operating points.

Calculation discipline

Copper loss scales with I²

Branch and output copper resistive losses are computed using user-entered length, conductor size and temperature assumptions, which remain clearly separated from manufacturer facts.

03 / What makes this a real engineering use case?

A conclusion supported by evidence—and a list of what is missing.

The prototype's purpose is not to produce an attractive but fictional cabinet temperature. It determines which losses can be modeled from published values and design assumptions, then explicitly blocks an unsupported compliance judgment.

01. Confirm the actual BOM

Exact fuse, holder, disconnect, SPD, conductor and controller SKUs; count both protected polarities only if that is the installed circuit design.

02. Obtain component power-loss curves

Include connection resistance, full-current losses, thermal derating and the permitted ambient conditions.

03. Validate enclosure heat-transfer data

The public size includes external mounting clamps. It does not provide a validated heat-transfer area or calibrated effective thermal conductance.

04. Perform applicable IEC verification

Follow the licensed standard's valid method, required inputs and limitations and, where applicable, compare with physical tests.

Demonstrated in the private software

Working engineering application

Editable string count/current, fuse arrangement, branch and output wiring lengths/sizes, operating ambient, CSV-style loss register, source-backed assumptions, scenario comparison and PDF report generation. The software also flags rating conflicts and suppresses unsupported fuse-loss extrapolation.

Not claimed

No fake compliance or agentic capability

The private calculation service is deterministic; it is not yet a qualified IEC TR 60890 implementation or a live AI-agent-connected thermal engineering system. Studio document intelligence and automated data ingestion are potential next-phase integrations, not features proven by this use case.
